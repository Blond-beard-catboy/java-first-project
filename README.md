# Генератор виртуального мира (multi-module Maven)

Проект разделен на 3 модуля, как если бы над ним работала команда из 3 человек:

1. `world-domain`  
   Ответственность: доменная модель и каталоги данных (сущности мира, справочники характеристик).
2. `world-generator`  
   Ответственность: бизнес-логика генерации и случайные параметры.
3. `world-cli`  
   Ответственность: консольный UX, ввод/вывод через `printf()`, задержки между строками.

## Запуск

Из корня проекта:

```bash
mvn -pl world-cli -am exec:java
```
